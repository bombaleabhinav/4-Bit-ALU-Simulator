Restoring Division Algorithm

Restoring division is an algorithm for unsigned binary division.

Steps:

  1. Initialize: A = 0, M = Divisor, Q = Dividend, Count = n.
  2. Shift Left: Shift AQ left by 1 bit.
  3. Subtract: A = A - M.
  4. Check Sign:
    • If A < 0 (Sign bit is 1): Q0 = 0, and Restore A (A = A + M).
    • If A ≥ 0 (Sign bit is 0): Q0 = 1.
  5. Decrement Count: Count = Count - 1. If Count ≠ 0, go to step 2.
  6. Result: Quotient is in Q, Remainder is in A.
